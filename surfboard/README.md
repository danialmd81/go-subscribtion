# Surfboard

Surfboard is a flexible and powerful network proxy tool designed for advanced users who need to manage, test, and automate proxy configurations. It supports a wide range of protocols and provides granular control over network traffic, making it ideal for privacy, bypassing censorship, and optimizing connectivity.

## Directory Structure

- [`1_subscription/`](./1_subscription/README.md):  
  Managed configuration and subscription profile options, including update intervals and strictness.

- [`2_general/`](./2_general/README.md):  
  General configuration options such as DNS, DoH, proxy test URLs, skip rules, and proxy server listeners.

- [`3_group/`](./3_group/README.md):  
  Proxy group definitions and rules for organizing and managing multiple proxies.

- [`4_rule/`](./4_rule/README.md):  
  Rule-based configuration for routing, filtering, and handling network traffic.

## Getting Started

Each subdirectory contains a `README.md` with detailed documentation and configuration samples for its respective section.  
Start by reviewing the [subscription](./1_subscription/README.md) and [general](./2_general/README.md) configuration options, then proceed to groups and rules as needed.
